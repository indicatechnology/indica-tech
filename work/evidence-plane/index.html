The grades / 03

Graded by what it cost to say it.

  1. E0Inferred

    The lines do not say it; it is an inference.

  2. E1Vague

    Said, but without specifics.

  3. E2Specific

    Said with a number, a date or a name.

  4. E3Impact

    It states an effect: “this costs us two days a week”.

  5. E4Behaviour

    An action already taken: “we switched vendors in March”.

  6. E5Committed

    A binding commitment, such as a signed order.

How it is held

Each line above is a test that fails the build, not a sentence in a deck. Results are kept by version, misses beside passes, so a slip shows up as a finding instead of being smoothed over.

The grader is frozen, so a grade means the same thing next month as it does today. A new grader adds its grades beside the old ones; none is rewritten.

Built / 05

Slice by slice, with a person at every gate.

01 · Slices

Small, finished pieces

Each slice ends in something you can open and run, and the whole test suite must pass before the next one starts.

02 · Gates

A person signs off

Four gates, each needing a human sign-off before the build moves on. Nothing promotes itself.

03 · Decisions

Written down first

Every judgement call with lasting effect is logged, with its reason, before the code is written.

04 · The road

Local first, cloud later

It proves itself on one machine first. The cloud gets the same promise, unchanged, once it has earned it.
